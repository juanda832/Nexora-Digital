# Nexora Digital

Sitio de portafolio de Juan Daniel Marín, desarrollador web en La Paz, Bolivia. Está hecho con HTML, CSS y JavaScript sin framework. Puedes verlo en [nexora-digital-phi.vercel.app](https://nexora-digital-phi.vercel.app/).

## Qué muestra

- Una presentación adaptable a escritorio y celular.
- Un caso empresarial publicado: [CIVILTELECOM S.R.L.](https://juanda832.github.io/civiltelecom/) y su [código](https://github.com/juanda832/civiltelecom).
- Un enlace directo a los servicios de Juan Daniel en [Contra](https://contra.com/s/UrWEg67k-custom-responsive-landing-page-or-html-css-and-java-script) y [Fiverr](https://www.fiverr.com/juanda812/build-a-responsive-landing-page-for-your-small-business).

Nexora es un proyecto de portafolio. El panel del inicio es una visualización conceptual y no representa resultados medidos de clientes. La captura de CIVILTELECOM corresponde al sitio publicado; las imágenes dentro de ese sitio son ilustraciones generadas con IA. Su formulario prepara un resumen local y no envía mensajes.

Esta página no almacena datos ni tiene un formulario propio. Para conversar sobre un encargo, abre uno de los enlaces a Contra o Fiverr.

## Ejecutar localmente

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático. No requiere instalación ni claves.
